# 🍽️ Local Chef Bazar – Homemade Food Marketplace

Local Chef Bazar is a full-stack MERN-based food marketplace platform that connects customers with talented local chefs and homemade meal providers. Users can explore delicious meals, place orders, manage favorites, submit reviews, and enjoy a secure and responsive food ordering experience.

## 🚀 Core Features

### User Features

* Secure user authentication and authorization
* Browse and explore homemade meals
* Search, filter, and sort meals
* View meal details
* Add meals to favorites
* Place meal orders
* Submit and manage reviews
* Responsive user dashboard

### Admin Features

* Manage users
* Promote users to Chef or Admin
* Handle role requests
* Monitor platform statistics
* Manage meals and platform activities
* View dashboard analytics

### Platform Features

* Fully responsive design
* Dark and Light mode support
* JWT-secured protected routes
* Dynamic statistics
* Customer reviews system
* Newsletter subscription system
* Skeleton loading states
* Secure Stripe payment integration
* Role-based access control
* MongoDB database integration

## ⚙️ Installation

### Clone Frontend

```bash
git clone https://github.com/jahid3741/local-chef-bazar-client.git
```

### Clone Backend

```bash
git clone https://github.com/jahid3741/local-chef-bazar-server.git
```

### Install Dependencies

```bash
npm install
```

### Run Client

```bash
npm run dev
```

### Run Server

```bash
npm start
```
